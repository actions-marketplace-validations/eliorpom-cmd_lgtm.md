    Setup

    1. Pick your widgets

      Widgets

    2. Create a token

      It lets the widgets count your private activity.

      1. Open the pre-filled token form: read-only, no expiration.
      2. Under Repository access, choose All repositories.
      3. Click Generate token and copy it.
      4. In your profile repository, open Settings → Secrets and variables → Actions and add a secret named LGTM_MD_TOKEN.

      The token can only read. Without it, the widgets show public activity only.

    3. Add the workflow

      Create the workflow on GitHub

      Show the file
      .github/workflows/lgtm-md.yml

    4. Show them in your README

      Paste this where the widgets should go.
