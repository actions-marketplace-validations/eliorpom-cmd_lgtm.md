          Create a read-only token

          It lets the widgets count your private activity. It can only read, and it never expires.

          Open the token form ↗
          1. Under Repository access, choose All repositories.
          2. Click Generate token and copy it.
          3. Open the secrets of your profile repository and add one named LGTM_MD_TOKEN, with the token as its value.
          What the token can read

          The form creates a fine-grained token with read-only access to Contents and Pull requests on All repositories. GitHub adds read-only Metadata on its own.

          The Action uses it to read:

          • your contribution calendar
          • the commit history of your repositories, to count commits per language
          • your merged pull requests
          • the languages of your repositories

          It can't push, open issues or change settings. The GIFs are committed by the workflow's own GITHUB_TOKEN.
