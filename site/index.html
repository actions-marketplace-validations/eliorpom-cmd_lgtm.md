    Setup

    Add them to your README

    The first run starts as soon as you commit the workflow.

    1. Your profile repository

      Public, and named exactly like your login

      Create it on GitHub ↗

    2. Pick your widgets

      None picked yet

    3. Create a token

      It lets the widgets count your private activity.

      1. Open the pre-filled token form: read-only, no expiration.
      2. Under Repository access, choose All repositories.
      3. Click Generate token and copy it.
      4. In your profile repository, open Settings → Secrets and variables → Actions and add a secret named LGTM_MD_TOKEN.

      Without it, the widgets show public activity only.

      What the token can read

      The form creates a fine-grained token with read-only access to Contents and Pull requests on All repositories. GitHub adds read-only Metadata on its own.

      The Action uses it to read:

      • your contribution calendar
      • the commit history of your repositories, to count commits per language
      • your merged pull requests
      • the languages of your repositories

      It can't push, open issues or change settings. The GIFs are committed by the workflow's own GITHUB_TOKEN.

    4. Commit the workflow

      The button opens GitHub with the workflow filled in. Click Commit changes.

      Create the workflow on GitHub ↗

    5. Paste the images in your README

      Copy README.md from the panel and paste it where the widgets should go. The last line, Made with LGTM.md, is optional.

    6. Check it worked

      Open the Actions tab of your repository. The first run takes about a minute. Until then the images show as broken.

      See your profile ↗
